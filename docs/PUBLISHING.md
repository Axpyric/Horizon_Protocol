Hakumadi — Publishing metadata and ASCAP note

This file is a small working note for recording publishing / rights metadata you may want to attach to assets
ingested into the Hakumadi registry. It is intentionally manual — fill in the fields and keep the file alongside
your repository for quick reference.

Example:

  steward: "Axpyric"
  pub_entity: "Hakumadi"
  ascap_id: "123456789"
  pr_society: "ASCAP"
  publisher_roles:
    - name: "Axpyric"
      role: "writer"
      ipi: "000000000"
    - name: "Hakumadi"
      role: "publisher"
      ipi: "111111111"

Notes:
- This file is informational only. For legal certs and registrations, use ASCAP’s official tools.
- Do not use this as a substitute for a formal publishing agreement; consult counsel if needed.

# v0.1.0 — Phase A+B+C2 demo initial

This is the draft release body for v0.1.0. It accompanies the hakumadi/init-v1 branch and the initial demo commit.

Highlights
- Phase A+B+C2 demo initial: deterministic fingerprinting, envelope signing, reconciliation, trust scoring, and a SQLite-backed registry with safe upsert behavior.
- Includes a local demo runner (run_local_demo.py) which demonstrates key generation, deterministic fingerprint creation, signing, and ingestion into the registry.
- Registry implementation: registrar/registry.py — uses canon/haunted_hoard.db (SQLite) and supports idempotent upserts to avoid ingestion failures on re-submission.
- Trust scoring: scorer/ (ruleset_v1.yml) with deterministic scoring and interpretation thresholds.

Quick notes for reviewers
- Generate an encrypted Ed25519 key before running the demo: `python signing/generate_key.py` (writes keys/private_ed25519.enc).
- Run the demo: `python run_local_demo.py` — inspect daemon/out for signed envelopes and canon/haunted_hoard.db for stored registry nodes.
- This is an initial prototype: expect to iterate on the data model, signature verification mechanics, and CI/tests.
